# passerby

（得鹿梦鱼）passerby是一个快速、简洁且高效的博客框架。passerby使用Markdown编写文档，并可以将转化为html,在gitlab和github上发布

## 使用

修改`data`目录下certificate.json的文件内容
修改`data`base.json的文件内容
执行命令`npm run general`生成静态页面
执行命令`npm run preview`预览静态页面
